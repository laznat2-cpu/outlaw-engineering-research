# ODIN / TV-PI

ODIN is a Raspberry Pi 5-based shop development and test system.

It is used to prototype software, dashboards, local-model workflows, remote-access tooling, and integration concepts before those ideas are deployed into WARDEN.

## Research Themes

- local model evaluation
- dashboard and UI prototyping
- remote development and system administration
- agent/workflow experimentation
- software validation before vehicle deployment

ODIN serves as the lower-risk development environment for concepts intended for later use in the vehicle platform.
