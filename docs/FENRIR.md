# FENRIR

FENRIR is an experimental vehicle integration platform based on a 2012 Jeep Wrangler JKU.

The platform combines a GM performance powertrain with custom drivetrain, suspension, steering, power distribution, vehicle electronics, CAN integration, camera systems, telemetry, and edge computing.

## Research Themes

- multi-network CAN observation
- bench-first integration methodology
- vehicle-state modeling
- telemetry and event logging
- power-distribution design
- camera and sensor integration
- modular electronics packaging
- validation of harness routing, serviceability, and fault isolation

## Safety Approach

Live-vehicle integration is staged. Passive observation and bench validation precede active interaction, and AI-assisted functions are kept separate from deterministic safety-critical control.
